# NCI_Project

## Project Description
This project is a Household Chores Distribution System for shared houses.

## Perpose of this project


## Main Features
- Create household groups
- Invite members
- Create chore cards
- Assign chores
- Update chore status
- Track chore completion

## Technology Stack
- Python
- Django
- GitHub
